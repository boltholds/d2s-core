# План испытаний и критерии приёмки

**Статус:** Proposed acceptance contract.

## Окружения

- Linux первым, затем другие ОС согласно поддержке SDK.
- Несколько **отдельных процессов**, а не только unit tests.
- Один хост, два хоста в LAN, затем маршрутизируемые подсети/VPN.
- Фиксировать версия/коммит Fast DDS, компиляторы, ОС, CPU, NIC, QoS, payload и topology.

## Local MVP — минимальные сценарии

| Проверка | Ожидаемое поведение |
|---|---|
| C++ writer / Python reader | Совместимое типизированное сообщение доставлено |
| Python writer / C++ reader | Обратное направление работает |
| Несовместимый type | Явная ошибка/диагностика, не бесконечное ожидание |
| Несовместимый QoS | Наблюдаемая причина отсутствия matching |
| Рестарт reader | Восстановление обмена согласно выбранному QoS |
| Рестарт writer | Нет use-after-free; корректный reconnect |
| Нет читателей | Поведение publish задокументировано |
| Медленный reader | Ограниченные буферы и проверяемое backpressure |
| Resource release | После close нативные сущности освобождаются |
| Без брокера | LAN обмен функционирует автономно |

Не путать прохождение приложения `publish` и доказательство сохранности события.

## SDK/Interop CI

- Build matrix, ABI version checks.
- Wire type compatibility для IDL primitives/containers.
- Cancellation/timeout/reentrancy tests для каждого языка.
- Leak sanitizer/ASan/TSan по применимости, race tests в Go, unsafe audit в Rust.
- Invalid input + fuzzing schema parsing/bridge envelopes.
- Проверка корректного cleanup после неожиданного завершения процесса.

## Federation — дополнительные acceptance tests

1. Пять доменов с разрешёнными и запрещёнными рёбрами.
2. A знает только непосредственных соседей; остальной граф не обязателен.
3. Запрет A→D не обходится через C или новый маршрут.
4. Cycle A→B→C→A не вызывает вечной пересылки.
5. Route discovery bounded по времени, hops и памяти.
6. Отказ одного peer не разрушает независимые достижимые сегменты.
7. Поддельные объявления и просроченные политики отклоняются.
8. Новый сосед не раскрывает частные Topics без соответствующих прав.
9. При разрыве WAN данные/гарантии соответствуют контракту, а не неявному «exactly once».

## Benchmark protocol

Измерять throughput, p50/p95/p99 и хвосты задержек для разных payload sizes и числа readers, отдельно при QoS best-effort/reliable; рядом — baseline Fast DDS, чтобы видеть overhead D2S. До измерений не задавать произвольные «высокая производительность» или числовые SLA как факт.
