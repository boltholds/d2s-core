# D2S Platform — документация

**Статус:** Architecture proposal / pre-implementation  
**Срез:** 2026-11-05  
**Репозиторий:** [boltholds/d2s-core](https://github.com/boltholds/d2s-core)  
**Лицензия:** см. [LICENSE](../LICENSE) (Apache-2.0)

D2S Platform — планируемая открытая платформа обмена типизированными данными между приложениями и устройствами. Локальное ядро предполагается строить над eProsima Fast DDS; в дальнейшем — добавить SDK для нескольких языков и необязательную децентрализованную федерацию сетей.

> **Внимание:** существование документа НЕ означает наличия реализации. Все API, wire-format, политики и критерии здесь — предложения до подтверждения кодом и тестами. Содержимое `docs/` — проектная спецификация, а не описание работающего релиза.

## Словарь статусов

- **Decision (намерение):** согласованное направление проектирования, но ещё не доказанная реализация.
- **Proposal:** возможный механизм/API; совместимость не гарантируется.
- **Deferred:** не входит в MVP.
- **Implemented:** допустимо писать только при наличии кода и тестов.

Порядок приоритетов: работоспособный и проверяемый local-first Pub/Sub → межъязыковые SDK → эксплуатация и сетевые сценарии → федерация. Вопросы безопасности и корректности доставки нельзя откладывать до внедрения global mode.
